One command first invalidates the exact prior parity report files, clears Gradle's generated test outputs with `cleanTest`, runs the unfiltered full test suite, and accepts no XML if Gradle or the adapter fails. That mode cannot report parity PASS: it accepts only a clean mapped JUnit execution and the exact owner-linked blocker set, records `ci_validation_status=PASS` while overall fixture status and parity remain `BLOCKED`, and fails for any mapped failure, skip, missing selector, provenance failure, catalog error, or unexpected blocker. The default combined runner remains strict and exits nonzero while empty selectors remain.
