# P9-5 closeout — optional-mod integrations and intentional-deviation contract

StoryNPCs implements no optional-mod integration of any kind; this is a decision record, not an implementation.

## The decision

**StoryNPCs implements no Pixelmon or Cobblemon integration.** This is an intentional deviation from the target, not a gap awaiting implementation:

- **User-visible behavior:** Every StoryNPCs feature (dialogue, quests, factions, trading, banking, roles) behaves identically whether or not Pixelmon or Cobblemon is installed alongside it. No StoryNPCs GUI, command, event, or persisted schema exposes a Pixelmon/Cobblemon-specific field or capability.
- **Absent-mod behavior:** Trivially safe — StoryNPCs contains no code path that references either mod, so there is no optional class to fail to load and no capability-detection branch that could misfire. This is the strongest possible form of "no optional class load crashes a server without the dependency": the class is never referenced, checked for, or conditionally loaded at all.
- **Supported-version range / load-order behavior / permission boundary:** Not applicable — there is no integration surface for these to apply to.
- **Migration path:** None needed. A CustomNPCs server using Pixelmon/Cobblemon-specific NPC behavior has no StoryNPCs equivalent to migrate to; that capability is simply not offered. If this is revisited in the future, it should start as a new granular issue against a supported version range of one specific game (Cobblemon, the actively maintained NeoForge-native Pokémon mod, would be the more sensible integration target than the older Forge-only Pixelmon, if either is pursued).

## Evidence

- `tools/parity/test_p9_5_optional_integrations.py`, 2 tests:
  - `test_manifest_integration_helper_set_matches_documented_deviation` — asserts the manifest's Pixelmon/Cobblemon symbol set is exactly the 7 listed above; a future manifest regeneration that finds a different set will fail this test and force this closeout to be revisited rather than silently going stale.
  - `test_no_source_file_references_pixelmon_or_cobblemon` — scans every file under `src/main` and fails if any contains either mod's name, mechanically enforcing the "no integration implemented" claim rather than relying on a one-time manual grep.
- `python -m unittest discover -s tools/parity -p "test_*.py"`: 110 tests passed (108 pre-existing + these 2).

## Explicit scope

This closes P9-5 for the integration surface the target artifact actually contains: exactly the 7 Pixelmon/Cobblemon helper classes, and nothing else was found. It does not certify runtime parity for any other domain, and it does not claim that no other Minecraft mod could ever meaningfully integrate with StoryNPCs — only that the target's own optional-integration surface has been fully enumerated and accounted for.
